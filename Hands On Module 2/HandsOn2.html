Struktur Silabus Mata Kuliah Pemrograman Web

Mata kuliah ini membekali mahasiswa dengan kompetensi rekayasa aplikasi web modern. Berikut adalah pembagian materi ajar:

Sisi Klien (Front-End)

  1. Modul 1: Fondasi Arsitektur Web & HTML5 Semantik
  2. Modul 2: Standardisasi Kode & Pengorganisasian Konten
  3. Modul 3: Rekayasa Media Digital & Dasar CSS
  4. Modul 4: Tata Letak Grid, Flexbox, & Bootstrap

Sisi Server (Back-End)

  1. Modul 5: Pemrograman PHP Modern
  2. Modul 6: Pemodelan Basis Data Relasional
  3. Modul 7: Manipulasi SQL & phpMyAdmin
